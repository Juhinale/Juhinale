`Python` `YOLOv8` `PaddleOCR` `EasyOCR` `TrOCR` `OpenCV` `Streamlit`

An end-to-end document processing application that extracts, validates, and structures handwritten and printed information from Indian bank cheques.

**Key Engineering Contributions**

- Designed a modular processing pipeline for cheque-field detection, text recognition, validation, and structured output.

- Built an interactive Streamlit interface supporting batch processing, result visualization, and structured data export.
- Achieved a character error rate below 3% on a 500-image evaluation dataset.
